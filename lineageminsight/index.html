Q.05

홈페이지 노출 화면 — 샘플

실제 매니아 홈페이지에 노출될 인사이트 상품 영역과 매니아가 쏜다 배너의 디자인 시안입니다. 이미지 기반 와이어프레임이 아닌 실제 데이터로 채운 모형입니다.
핵심 어필 로직

가격 차이의 원인 = 스펙 차이

바로템(외부 거래소) 거래 실적을 시세 잣대로 하되, 아이템매니아 매물과 바로템 매물 사이의 가격 차이는 본질적으로 계정 스펙 차이에서 발생합니다. 같은 서버·클래스·레벨이라도 신화 보유 여부, 전설 스킬 수, 이동악세 보유 등에 따라 시세가 달라집니다.

따라서 인사이트 상품 한줄 분석의 핵심 메시지는 단순히 "저렴하다 / 비싸다"가 아니라 "이 가격대에 이 스펙이 있다"는 가성비 논리가 되어야 합니다.

외부 노출 보안 원칙

경쟁사(바로템) 데이터 출처 절대 비공개

바로템은 내부 시세 잣대 용도로만 사용. 사용자 노출 화면 어디에도 경쟁사 명칭이 표기되지 않습니다. 외부 표현은 "유사 매물 시세 대비", "동급 매물 평균 대비", "동일 조건 시세 분석" 등 익명화 표현을 사용하고, 모든 분석 글은 "매니아 자문단 분석" 명의로 게시합니다.

운영 매뉴얼은 뇌신·군주·요정을 인기 클래스로 정의했으나, 실제 거래 데이터에서는 뇌신·마검사·총사·마법사 순으로 표본이 많습니다. 군주는 만렙 91 표본 4건으로 운영 불가입니다. 매뉴얼의 스펙 점수 ×2 가중치 "클래스 수요도" 항목은 실제 데이터 기반 재정의가 필요합니다.

Q.07

매니아가 쏜다 — 혜택 기준 추천

매니아가 쏜다는 별도 트랙(트랙 B)이지만, 운영 시작 시 적용할 자격 기준 추천안을 제시합니다. 스펙 의무화 이후 데이터 환경 변화를 고려해 3개 안을 검증했습니다.

7.1현재 데이터 단계별 필터링 결과

가격 조건만 적용하면 251건이지만, 스펙·신뢰도 조건을 추가하면 후보가 급감합니다. "심사단이 엄선한 우량 매물" 정의에는 가격뿐 아니라 매물 자체의 품질 검증이 필요하기 때문입니다.

7.2운영 기준 추천 3개 안

A안 · 운영 시작용 59건

느슨한 기준

조건: 가격 -50%~-20%, 원본그룹 5건+, 스펙 1개 이상 기입
혜택: 수수료 3% 할인 + 안심 보상 200%
특징: 후보 수 확보 가능하나 품질 검증 약함

B안 · 권장 3건

표준 기준

조건: A안 + 결제내역 + 그룹 10건+ + 스펙 2개+
혜택: 수수료 3% 할인 + 안심 보상 200%
특징: 우량 검증 강화. 현재 데이터로는 후보 부족

C안 · 엄격 2건

프리미엄 기준

조건: B안 + 스펙 3개+ + 만렙 한정
혜택: 수수료 4% 할인 + 안심 보상 200% + 인사이트 우선 검토
특징: 데이터 누적 후 PLUS 등급 분리 운영 시 적용

최종 권고

이중 트랙 운영 + 스펙 의무화 후 활성화

트랙 B에서 A안(일반) + C안(PLUS) 이중 운영. 현재는 후보 수가 적어 스펙 입력 의무화 후 30일 이상 데이터 누적한 뒤 시작하는 것이 합리적입니다. 인사이트 상품 운영을 먼저 안착시키고 매니아가 쏜다는 후속 단계입니다.

Q.08

실행 로드맵

운영 매뉴얼이 정의한 3단계 자동화 로드맵(수동 → 반자동 → 자동화)에 맞춰 각 단계에서 무엇이 가능하고 무엇이 막혀 있는지를 명확히 정리했습니다.

8.1트랙 A vs 트랙 B 운영 영역 구분

트랙 A · 즉시 시작

매니아 인사이트 상품 운영

  • 일일 3슬롯: 저평가 1 · 적정가 1 · 고가 1
  • 대상: 데포 × 뇌신/마검사/마법사/총사 × 91레벨
  • 분류: 가격 기반 3등급 + 매물 특성 라벨
  • 리스크 필터: -50% 이하 / +200% 이상 자동 제외
  • 운영자 검수 후 매물별 한줄평 + 리포트 작성
시작 가능: 1주 이내
트랙 B · 보강 후 시작

매니아가 쏜다 혜택 프로그램

  • 전제: 매물 등록 시 핵심 스펙 6개 의무 입력
  • 대상 매물 풀: A안 기준 (스펙 1개+ 우량)
  • 혜택: 수수료 3% 할인 + 안심 보상 200%
  • PLUS 등급: C안 기준 (만렙 스펙 3개+) — 데이터 누적 후
  • 고스펙·HOT 등급도 함께 활성화
시작 가능: 등록 폼 개선 + 30일 누적 후

8.2단계별 실행 일정

PHASE 1 · Week 1

인사이트 상품 운영 시작

데포 4대 클래스 × 91레벨 일일 3슬롯 운영 개시.

  • 96개 유효 그룹 시세 기준값 적용
  • 운영자 1인 검수 → 매물 선정 → 한줄평·리포트 작성 → 게시
  • D항목 리스크 자동 필터 적용
PHASE 2 · Week 2~4

매물 등록 폼 스펙 의무화 협의

개발팀 협의 + 핵심 스펙 6개 항목 필수 입력 도입.

  • 필수: 신화변신/성물/인형 + 신화·전설 스킬수 + 이동악세 + 결제내역
  • 신규 등록부터 적용 (기존 소급 없음)
  • 목표: 스펙 기입률 67% 미기입 → 95%+ 기입
PHASE 3 · Month 2~3

매니아가 쏜다 + 5등급 시스템 활성화

스펙 데이터 누적 후 트랙 B 영역 가동.

  • 매니아가 쏜다 일반(A안) 시작
  • 고스펙·HOT 등급 활성화
  • VALUE_SCORE 기반 가성비 분석 도입
  • 준만렙(89~90레벨) 시장 확장
PHASE 4 · Month 4+

반자동 → 자동화 전환

클래스별 30건+ 누적 후 추천 자동화.

  • 판매중 상품 자동 크롤링·파싱 도입
  • KPI 기반 추천 알고리즘 학습 (CTR·전환율)
  • 매니아가 쏜다 PLUS(C안) 활성화
  • 전 서버·전 클래스 확장
Q.09

추가 필요 정보

현재 데이터로 인사이트 상품 시작은 가능하지만, 시스템 완성도와 트랙 B 진입을 위해 추가 데이터 수집이 필요합니다. 우선순위에 따라 분류했습니다.
진행 예정 · 후속 보완

아이템매니아 자사 시세 데이터 추가 분석 예정

현재 보고서는 바로템(외부 거래소) 거래완료 데이터를 시세 잣대로 한 1차 분석입니다. 정확도와 신뢰도를 높이기 위해 아이템매니아 자사 거래완료 데이터를 추가로 수집하여 이중 잣대 분석으로 보완 진행 예정입니다. 자사 매물의 텍스트·이미지 데이터에서 이미지 분석을 통한 스펙 자동 추출까지 함께 진행하여, 현재 67% 미기입 문제 해결과 함께 매니아가 쏜다 트랙 B 조기 활성화도 가능할 것으로 예상됩니다.

  • 1단계: 아이템매니아 거래완료 데이터 수집 채널 확보
  • 2단계: 매물 이미지(스크린샷)에서 스펙 자동 추출 (Vision 분석)
  • 3단계: 바로템 + 매니아 이중 잣대 비교 분석 보고서 작성
필수 · 즉시

01. 아이템매니아 판매중 매물 수집 채널

현재 보유 데이터는 바로템(외부 거래소) 거래완료 — 시세 잣대 역할. 인사이트 상품으로 게시할 추천 대상은 아이템매니아 판매중 매물이 필요합니다. 내부 시스템 직접 연동 또는 별도 수집 채널 구축 협의 필요.

필수 · 즉시

02. 매물 등록 폼 스펙 입력 의무화

67% 미기입 상태로는 고스펙·HOT 등급 작동 불가, 매니아가 쏜다 운영 불가. 신화변신/성물/인형 + 스킬 + 이동악세 + 결제내역 의무 입력 도입.

권장 · 1~2개월

03. 게시 후 KPI 데이터 수집

매뉴얼 정의 6개 KPI(CTR · 상세진입률 · 구매전환율 등) 일일 기록. 어떤 등급/가격대가 잘 팔리는지 학습 데이터로 활용.

권장 · 1~2개월

04. 사기 매물 라벨 데이터

운영자가 D항목 리스크로 제외한 매물의 사유 기록. 자동 필터 정확도 향상 및 학습 데이터로 활용.

장기 · 3~6개월

05. 서버 메타 변화 추적

서버 합본 · 신규 콘텐츠 출시 등 시세 급변 시점 표시. 패치 이전·이후 데이터 분리 분석 필요.

장기 · 3~6개월

06. 클래스 인기도 재정의

매뉴얼의 "뇌신·군주·요정 인기" 가설을 거래량·회전율 데이터로 재검증. 스펙 점수 가중치 ×2 항목 재정의.
